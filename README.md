# Juego Gato (Tic-Tac-Toe)

Este es un simple juego de Gato (Tic-Tac-Toe) para Android.

## Descripción

El juego consiste en un tablero de 3x3 donde el jugador compite contra la computadora. El objetivo es ser el primero en conseguir tres de sus marcas en una fila, columna o diagonal.

## Características

* Jugador contra la Computadora.
* Detección de ganador y empate.
* Interfaz de usuario sencilla.

## Construido con

* [Kotlin](https://kotlinlang.org/)
* [Android Studio](https://developer.android.com/studio)
